# 📱 SNS 서비스의 데이터를 통한 데이터 분석

## 👤 프로젝트에서 진행한 역할

---

### 1. GCP를 이용한 Cloud 기반 데이터 분석 환경 제공

프로젝트 데이터 분석 전 과정을 Cloud 호나경에서 수행할 수 있도록, Google Cloud Plarform(gcp) 기반의 데이터 분석 인프라를 구축하였다. BigQuery를 활용하여 대규모 사용자 로그와 투표 데이터를 저장하고, 최적화된 SQL 쿼리를 통해 빠른 데이터 조회·분석이 가능하도록 환경을 구성하였다. 또한 Cloud Storage와 BigQuery 간의 데이터 파이프라인을 설계·구현하여 데이터 적재 및 관리 과정을 자동화하였다.

### 2. Vertex AI와 사전 훈련된 Gemini Pro 2.5 모델을 통한 질문 텍스트의 카테고리 생성

Google Cloud Vertex AI 환경에서 **사전 훈련된 Gemini Pro 2.5 모델**을 호출하여 질문 텍스트를 의미 단위로 분석하고, 해당 문장의 주제와 맥락에 기반한 카테고리 키워드를 자동 생성하였다. 모델 입력 전 불필요한 기호·불용어를 제거하는 전처리 과정을 수행하였으며, 모델 출력 결과를 구조화된 데이터셋으로 변환하여 후속 연관 분석 및 네트워크 분석에 활용 가능한 핵심 피처를 확보하였다.

### 3. 질문에 대한 카테고리 키워드를 연관 분석, 네트워크망을 통한 군집화

연관 규칙 분석을 적용하여 카테고리 키워드 간의 동시 출현 패턴을 도출하고, Python 기반의 NetworkX 라이브러리를 호라용해 네트워크망을 구성하였다. 네트워크 중심성과 군집 계수를 분석하여 주요 주제 그룹을 식별하고, 이를 바탕으로 재투표 유저의 고나심 주제 및 행동 패턴을 시각적으로 표현하였다. 도출된 군집별 특징을 기반으로 리텐션 개선 전략의 핵심 방향성을 제안하였다.

## 💡프로젝트 내 회고

---

이번 프로젝트는 재투표 유저의 행동 패턴 분석과 이를 통한 리텐션 개선 전략 도출을 목표로, Google Cloud 기반의 전 주기 데이터 분석 환경을 직접 설계하고 구현한 경험이었다.

특히 GCP BigQuery와 Vertex AI, 그리고 사전 훈련된 Gemini Pro 2.5 모델을 연계해, 텍스트 기반 데이터에서 의미 있는 인사이트를 추출할 수 있었던 점이 인상 깊었다.

### 1. 기술적 성취

- Cloud 기반 분석 환경 구축
    - GCP의 BigQuery를 이용해 대규모 로그 데이터를 빠르고 안정적으로 처리할 수 있는 분석 환경을 설계하였다.
- 최신 LLM 활용 경험
    - Vertex AI 환경에서 Gemini Pro 2.5를 호출해 질문 텍스트의 의미 기반 카테고리를 생성하였다.
    - 시전 훈련된 대규모 언어모델(LLM )을 활용함으로써, 전통적인 NLP 전처리보다 빠르고 정확한 피처 엔지니어링이 가능하다는 것을 체감했다.
- 연관 분석과 네트워크 시각화
    - Association Rule Mining을 통해 키워드 간 관계를 파악하고, NetworkX 기반의 네트워크 분석을 통해 주제별 군집을 시각적으로 표현하였다.

### 2. 배운 점

- **Cloud 환경 최적화의 중요성**: 대규모 데이터를 다룰 때는 쿼리 최적화와 리소스 관리가 분석 속도와 비용 절감에 직결된다.
- **LLM과 AutoML의 융합 가능성**: 사전 훈련된 LLM을 기반으로 한 피처 생성은 분석의 출발선을 높여주었으며, 특히 도메인 레이블링 작업에서 높은 효율성을 제공했다.
- **데이터 시각화의 설득력**: 네트워크 시각화는 단순 수치보다 관계를 직관적으로 보여줘 의사결정 과정에서 강력한 근거 자료가 될 수 있었다.

### 3. 한계와 개선점

- Gemini Pro 2.5 모델은 강력했지만, 모델의 출력이 항상 일관적인 것은 아니어서 후처리 로직이 필요했다.
- 네트워크 분석에서 군집 해석의 주관성이 개입될 여지가 있어, 추가적인 정량 지표나 설문 데이터를 보완 자료로 확보할 필요가 있었다.
- 리텐션 개선 전략이 가설 단계에 그쳤으므로, 실제 운영 환경에서의 A/B 테스트를 통해 전략의 효과성을 검증하는 후속 연구가 필요하다.

### 4. 개인 성장

이 프로젝트를 통해 **Cloud 기반 데이터 분석 전 과정**을 스스로 설계·구현하며 기술적 자신감을 얻게 되었고, LLM을 실무 분석에 접목하는 경험을 쌓았다.

또한, 단순 분석을 넘어 **인사이트를 서비스 개선 전략으로 연결**하는 사고 방식을 체득했다. 앞으로는 분석 결과의 실효성을 높이기 위해 실험 설계 및 비즈니스 적용까지 고려한 프로젝트를 수행하고자 한다.
